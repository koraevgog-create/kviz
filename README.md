# Сокровища мудрости

Библейская финансовая викторина для 1–4 команд. Статический сайт на GitHub Pages.

## Структура

- `index.html` — точка входа, метаданные и подключение локальных ресурсов.
- `assets/styles.css` — адаптивный дизайн.
- `assets/app.js` — игровая логика, управление командами, таймер, сохранение.
- `data/questions.js` — банк из 30 библейских вопросов с ответами и ссылками.

## Запуск

Откройте `index.html` или опубликованный сайт GitHub Pages. Внешние библиотеки и сборка не требуются. Все ресурсы загружаются из того же репозитория.

## Механика

6 категорий × 5 вопросов (100–500 очков), до 4 команд, ведущий присуждает баллы, 60-секундный таймер, отсутствие штрафа, продолжение партии через localStorage.

## Примечания

Прогресс хранится локально в браузере. Для синхронизации команд на разных устройствах потребуется сервер. Вопросы и ссылки на Писание следует редакционно проверить перед публичным мероприятием.
